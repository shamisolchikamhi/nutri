# Project instructions

## Weekly credit guardrail

Treat 50% of the account's weekly Codex allowance as reserved for other projects.

- Keep work in this repository economical: use the smallest sufficient investigation, avoid optional rework, and run only verification relevant to the change.
- Do not start broad, long-running, or exploratory work without first stating the expected scope and asking for confirmation.
- If the user reports that this project's usage has reached 50% of the weekly allowance, stop additional nonessential work and ask before continuing.
- This is a soft guardrail: Codex cannot read or enforce the account usage meter from repository instructions. Tell the user when exact enforcement would require checking the Codex usage page.
